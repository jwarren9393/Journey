# Journey — Development Roadmap

A phased plan for building the book-writing app. Phases are flexible — we'll refine as we go.

## Phase 0: Foundation (current)

- [x] Flutter project scaffold
- [x] Folder structure (feature-based architecture)
- [x] App theme and routing shell
- [x] GitHub repository
- [ ] Define core features and user flows together

## Phase 1: Core Writing Experience

- Book/project model (title, description, metadata)
- Chapter and scene structure
- Basic text editor (plain text or rich text — TBD)
- Local persistence (save drafts on device)
- Library view (list of books/projects)

## Phase 2: Writing Tools

- Word count and writing goals
- Focus/distraction-free mode
- Search within a project
- Basic formatting (headings, emphasis, etc.)
- Export (Markdown, plain text, or PDF — TBD)

## Phase 3: Organization & Planning

- Notes and research attachments
- Character/location/plot notes (worldbuilding)
- Outline view (drag-and-drop chapters — TBD)
- Tags and categories

## Phase 4: Polish & Platform

- Onboarding and empty states
- Settings (theme, font, spacing)
- Desktop optimizations (keyboard shortcuts, multi-panel layout)
- Mobile optimizations (touch, offline-first)
- Backup and sync (cloud — TBD)

## Open Questions

Use this section to capture decisions as we discuss them:

- **Target platforms**: Windows, macOS, mobile, web — which first?
- **Editor style**: Plain text, Markdown, or rich text (WYSIWYG)?
- **Data storage**: Local-only first, or cloud sync from the start?
- **Book structure**: Chapters only, or chapters + scenes?
- **Monetization**: Free, one-time purchase, subscription — or personal project?
